CREATIVE TECHNOLOGY CHALLENGE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Because no predefined assets are being provided, you have greater creative freedom.

Consider whether the website can benefit from:

- A procedural 3D hero
- Interactive WebGL
- Generative SVG
- Canvas animation
- Particle systems
- Dynamic typography
- Interactive cursor
- Scroll-driven scenes
- Animated background systems
- Spatial UI
- Data visualization
- Physics-inspired motion
- Interactive product visualization

Do not use all of them.

Select only the techniques that create the strongest experience.

The goal is NOT:

"How many technologies can I put into this website?"

The goal is:

"How impressive can I make this experience while keeping it coherent, usable, and fast?"
